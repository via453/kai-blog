这是 KAI 的个人blog 的第一篇示例文章。它的作用不是正式发布观点，而是告诉未来的我：一篇文章应该怎么写，怎样分类，怎样加标签，以及怎样控制摘要。

<!--more-->

## 写在前面

每篇文章开头都有一段 `front matter`，也就是被 `---` 包起来的配置区。常用字段包括：

- `title`：文章标题
- `date`：发布日期
- `draft`：是否为草稿，`false` 才会正常发布
- `description`：文章摘要
- `categories`：文章分类
- `tags`：文章标签

## 推荐的文章结构

一篇经验文章可以按这个结构写：

1. 背景：为什么要做这件事。
2. 问题：遇到了什么阻碍。
3. 过程：尝试了哪些方法。
4. 结果：最后怎么解决。
5. 复盘：下次可以怎么做得更好。

## 图片怎么放

文章图片建议放在：

```text
static/images/
```

正文中这样引用：

```markdown
![图片说明](/images/example.png)
```

## 代码怎么写

如果文章里需要记录命令或代码，可以使用代码块：

```bash
hugo server -D
```

## 结尾

真正有价值的博客，不一定要写得很长，但要尽量具体。把一次问题、一次选择、一次复盘写清楚，就已经是在积累自己的经验系统。
